# InAmigos Foundation - NGO Awareness Website

## Overview

This project is a responsive NGO Awareness Website created for the InAmigos Foundation internship assignment. The website aims to spread awareness about the organization's mission, ongoing projects, social impact, and volunteer opportunities through a clean and engaging user interface.

## About InAmigos Foundation

InAmigos Foundation is a Section 8 registered non-profit organization established on September 23, 2020. The organization works towards creating sustainable social impact through initiatives focused on education, women empowerment, food distribution, environmental sustainability, animal welfare, and skill development.

## Features

* Responsive Design (Mobile, Tablet, Desktop)
* Modern NGO-Themed User Interface
* Hero Section with Call-to-Action
* About Us Section
* Ongoing Projects Showcase
* Social Impact Statistics
* Volunteer & Support Section
* Image Gallery
* Contact Information Footer
* Smooth Scrolling Navigation
* Interactive Hover Effects
* Animated Counters
* Mobile-Friendly Navigation Menu

## Installation & Usage

1. Clone the repository:

```bash
git clone https://github.com/your-username/inamigos-awareness-website.git
```

2. Open the project folder.

3. Launch `index.html` in your browser.

No additional dependencies or installations are required.
